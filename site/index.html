A draft primer for Magic's newest set, written before anyone has played it.

mulligan is an open-source simulator for Magic: The Gathering Limited. It reads a set's cards, then bots draft, build and play hundreds of thousands of full games under the real rules. From that comes a primer for the format: which colors to be in, which cards to take, and what winning decks look like. The tools below use the same numbers, and they switch over to real players' results from 17Lands as soon as the set is out.

The simulator is a good first guess, not an oracle. See How it works for how far to trust it.
